The agent: five stages, one human gate

A Python orchestrator fans out headless Claude Code workers. Each worker is sandboxed to WebSearch and WebFetch and must return JSON against a strict schema with enums, so answers can be scored field by field.

Trigger it yourself

Needs Python 3.10+ and a logged-in claude CLI. No API keys, no pip installs. Every stage caches per app, so reruns only redo what failed, and a hard budget cap stops spend.

# research one app end to end (41 = Shopify)
git clone __REPO__
cd composio-app-research
python agent/run.py scout  --apps 41
python agent/run.py ground --apps 41
python agent/run.py verify --apps 41

# all 100, resumable, BUDGET_USD caps spend
BUDGET_USD=48 ./agent/run_all.sh
python agent/run.py score && python agent/run.py export

How we know it is right

Accuracy by field, each pass

A field counts as correct when it matches the gold answer. Where the docs support two readings (Twilio's trial credit reads as free or as trial), the gold record accepts both. data.json lists exactly which values were accepted.

Grounding: do the cited pages say what the agent claims?

Checked with no LLM involved: fetch every evidence URL the scout cited, strip the HTML, and look for the quoted sentence. A dead link or a quote missing from the page means the claim was not read from that page, so the row is routed to review.
